# Audio sources

All eleven WAV files in this folder are original synthesized cues generated by
`scripts/generate-audio.mjs` for this project. They do not contain sampled audio,
Kahoot recordings, or third-party music.

- Format: 22,050 Hz, mono, 16-bit PCM WAV.
- Uses: click, alert, countdown, round start, answer lock, last seconds,
  correct/incorrect answer, leaderboard, final podium, and a four-second quiz intro.
- License: dedicated to the public domain under CC0 1.0. Attribution is optional.
- License reference: https://creativecommons.org/publicdomain/zero/1.0/
- Regenerate with `npm run assets`.

Kenney Interface Sounds was evaluated during planning (https://kenney.nl/assets/interface-sounds,
CC0). The shipped set uses original generated sounds instead, keeping the download
small and the timing consistent. No Kenney files are redistributed in this version.

`quiz-intro.wav` is an original melody, not the Kahoot theme. To supply your own
intro file, place it here and set `VITE_ROUND_INTRO_URL=/assets/audio/your-file.mp3`
in `.env.local`. Use a roughly four-second clip to match the visual sequence.
